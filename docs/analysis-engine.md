# 本地分析引擎 v0.3

## 已实现链路

完整抖音对标主页 + 个人方向 + 可选自己的主页 → 本地分析任务 → 浏览器证据包 → Codex CLI 结构化生成 → 引用校验 → 报告版本、账号搭建方案与候选卡。

本次真实测试的采集由当前 Codex 会话浏览器辅助完成，报告由网站后端实际调用模型生成。它不是手填报告，也不是预置样例；它仍不等于任意账号在没有浏览器连接时能够自动采集。

## 本机运行

Node.js 22 或更新版本，官方 Codex CLI 已安装并登录，执行 `npm start`，打开 http://localhost:4173/。
模型执行使用 CLI 自身的既有登录，不读取或复制认证文件，不需要新增模型 API key。若系统 PATH 无法找到原生程序，可为本机服务指定 YUELAO_CODEX_BIN 的可执行程序路径；网页请求不能覆盖执行程序或参数。

使用 stdin 传入背景及证据，--output-schema 约束结果，--ephemeral、read-only sandbox，关闭 shell_tool、shell_snapshot、apps、multi_agent 和 web_search。JSONL 出现未知 item 类型、失败事件、无成功结束或无有效引用时拒绝报告。纯输出类型白名单不等于证明所有安装插件均不可用；CLI 不是面向不可信租户的隔离服务。参考 [官方非交互模式](https://developers.openai.com/codex/noninteractive/)。

程序只监听 127.0.0.1，固定 Host、Origin 检查，随机本机令牌、正文大小与单并发限制。不要将这个个人 CLI 执行入口转为公网服务。

## 采集通道的独立状态

- host_browser：当前聊天用宿主浏览器读取已登录页面；需要运行中的会话协助，不声称网站已能调用 CUA。
- browser_extension：browser-collector 目录的 Chrome/Edge 实验扩展。持续站点授权限于抖音和 localhost:4173，不是 activeTab 临时授权。不读取 Cookies、私信、后台或隐藏状态。
- 用户选择“先看这次报告”，因此扩展未安装，也未完成扩展端到端验收。解析函数已通过 CUA 在真实主页/作品 DOM 上验证，不能替代扩展安装、消息传递与采集队列验收。
- 采集等待、验证码、模型失败、断线与取消都有真实状态；不会回落到 Xilo 历史样例。

公开页面采集最多30条已加载作品。已确认点赞语义的元素才进入指标比较，未知指标不参与高低样本排序。本人管理视图/私密标记拒收或跳过；章节只读取已识别作品容器内的章节面板。最多采集两条高互动、一条低互动作品的章节；总时间有界，轮询和新开标签前检查取消。

## 证据与结果

证据包绑定任务指纹、账号角色、URL、采集时间和来源方式。视频链接必须在该账号所提交作品列表中；可取得时验证作者链接，未取得则明确缺口。页面、标题、数字、章节摘要和视觉观察分开存储。

模型输出四个维度各至少2条，至少3条选题建议，六项搭建方案：定位、昵称、头像、简介、背景、搭建流程。每条保留材料 ID，区分观察、推断和建议。复制文案/提示词只改变剪贴板，不生成图片或修改平台资料。

完整视频逐字稿、镜头时序和后台数据当前未自动取得。章节摘要可能有识别错误，不能冒充逐字稿；点赞不是播放量，更不证明爆款因果、收入或转化。

原始采集包和后端任务放在 .local/，不进入公开 Git。浏览器保存报告快照。旧报告不随新方向改变，输入变更后待更新；同 job 重导入不重复。模型报告暂不使用旧人工编辑器，以免损坏多来源、建议类型和账号方案。
