# 本机抖音采集桥（实验版）

用途：网站提交指定账号 → 打开抖音主页 → 读取已呈现的公开资料与作品 → 取最高两条、最低一条的页面章节 → 回传本机工作台 → AI 自动生成报告。

不请求 cookies、浏览历史、私信或账号设置权限；不绕验证码，不拦截网络，不注入平台接口。仅请求抖音域名和本机 4173 端口权限。平台章节不是完整视频转录。

## 使用

1. 在 Chrome / Edge 的扩展管理页加载这个文件夹作为本地未打包扩展。
2. 阅读并确认抖音站点访问权限。
3. 在同一浏览器打开 http://localhost:4173/，登录抖音。
4. 输入对标主页、方向和个人主页，开始分析。出现验证码时在抖音页面自行完成，再等待采集；超时可回工作台重试。

仅支持完整 /user/ 主页链接；不支持分享短链。可见列表最多 30 条，未覆盖全部历史要保留缺口。
对标和本人主页分别采集；新打开的主页页签保留，临时作品页签采集结束关闭。
安装前必须由用户确认，尚未在用户浏览器加载和端到端验收。宿主辅助采集的验收不能代替扩展验收。
不要把本地 Codex 服务暴露到公网。

安全边界：这是本机个人原型。网站运行令牌随本地服务重启失效；只允许绑定的 loopback 站点与扩展请求。材料仅在 .local/ 与当前浏览器保存，报告生成会发送给现有 Codex 登录所对应的模型服务。
