# 月老 · 对标账号拆解

短视频创作工作台的第一个节点。当前为可点击原型，帮助用户保存研究材料、整理有来源的报告，并形成候选选题交接卡。

## 预览

- [打开本地原型](http://localhost:4173/)；用户选择本轮仅本地预览，不上传 Sites。
- 本地：Node.js 22+，执行 `npm start`，打开 http://localhost:4173/ 。无须安装第三方依赖。
- 点击“看一份拆解样例”，可预览报告、来源与候选卡。样例来自历史研究摘要，原始证据包未完整归档，非实时分析。

## 视觉版本 v0.2

参考 Mobbin 的 ISO Meet 公开设计，重新实现浅色工作台、精简表单、样例预览及三步研究导航。参考来源与设计原则见 [DESIGN.md](DESIGN.md)，产品范围见 [PRODUCT.md](PRODUCT.md)。

## 本轮功能

1. 输入抖音主页、账号方向及可选背景，建立独立研究任务。
2. 补充文字、图片、视频或文稿；文件字节保存到当前浏览器 IndexedDB。
3. 人工记录观察/推测，并为结论和候选建议关联材料。
4. 保存独立报告版本；输入变化后提示旧报告待更新。
5. 选取候选建议形成交接卡，保留来源、背景、适配理由和报告版本。
6. 导出研究 JSON、报告 Markdown、候选交接 JSON。导出不包含附件原文件，原文件可在材料页面单独下载。

数据存储在当前设备、浏览器与站点下，不跨设备同步。清除浏览器站点数据会删除本地记录。报告草稿暂存在当前页面，保存后才持久化。

## 能力边界

自动主页获取、模型分析、视频转录尚未接通。提交任意链接不会产生预置分析。人工报告明确标识来源；上传图片只表示已保存，不代表识别完成。

候选卡不表示最终入选、已排期或开始制作。完整选题池、日历、脚本、封面生成、视频制作、发布与复盘由后续对应功能承接。
