# 月老 · 短视频工作台

当前节点：对标账号分析与个人账号搭建。输入对标抖音主页、账号方向和可选个人主页，由真实证据驱动生成报告。

## 本地预览

需要 Node.js >=22。运行 `npm start`，打开 http://localhost:4173/。测试：`npm run check`、`npm test`。

真实模型生成使用本机已经登录的官方 Codex CLI。当前实现面向本机个人使用；不读取/复制凭据，不将 CLI 服务暴露公网。

## 当前能力

- 创建研究、浏览器本地保存与版本快照。
- 本地分析任务、状态恢复、取消、错误态与引用校验。
- 基于材料自动生成定位、选题、结构和个人借鉴建议。
- 个人账号搭建：定位、昵称候选、头像提示词、两版简介、背景建议、逐步搭建清单，一键复制。
- 候选内容卡与 JSON/Markdown 导出；原文件仍需单独交接。
- 独立历史样例，不用于伪装任意链接的自动结果。

## 采集现状

实际 Xilo 研究已通过宿主浏览器辅助采集，并由网站后端调用真实模型生成报告。公开 HTTP 请求未取得可用主页内容；CLI 也不会自动继承桌面浏览器登录。

`browser-collector/` 是待安装验收的 Chrome/Edge 公开页面采集桥。用户当前选择先看报告，未安装扩展。仅有网站页面、尚未连接浏览器时，会停在等待采集；不能宣称独立全自动已完成。

没有完整视频转录时，报告明确限制为标题/章节层面的分析。不得编造后台留存、收入和爆款因果。

实现、权限与证据说明见 [本地分析引擎](docs/analysis-engine.md)。项目治理见 [协作规则](CONTRIBUTING.md) 与 [项目治理](docs/project-governance.md)。

仅本地预览；未经用户进一步要求，不上传 Sites、不发布、不自动修改抖音资料、不合并 PR。
